# Mini Cloud

Личное демо-хранилище изображений на React. Интерфейс приложения и работа с файлами выполняются в браузере; Node.js нужен только для разработки и production-сборки.

## Запуск через Docker

1. Установите и запустите Docker Desktop.
2. В корне проекта выполните:

   ```bash
   docker compose up --build
   ```

3. Откройте http://localhost:8088.
4. Войдите с любым непустым именем и паролем.

Остановить контейнер: `docker compose down`.

## Локальная разработка

```bash
npm install
npm run dev
```

Production-сборка: `npm run build`. Тест: `npm test`.

## Возможности

- Имитация входа и защищённый маршрут дашборда.
- Перетаскивание и выбор нескольких изображений до 7 МБ каждое.
- Предпросмотр, поиск, фильтр по фото и удаление файлов.
- Изображения сохраняются отдельно в IndexedDB через `localforage`; `localStorage` хранит только демо-токен и имя пользователя.
- При недостатке места браузера приложение показывает понятное сообщение.

Хранилище привязано к браузеру и устройству: Docker контейнер не содержит загруженные пользователем файлы. Вход демонстрационный, без сервера и реальной аутентификации.
